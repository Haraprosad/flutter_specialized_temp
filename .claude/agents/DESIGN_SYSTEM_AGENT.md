# Agent: Design System Setup

**Invoked by**: `@agent design-system`

**Purpose**: Systematically configure the entire Design Management System (DMS) for this specific app — colors, typography, spacing, dimensions, motion — before any feature work begins.

**Reads first**: `.claude/skills/DESIGN_SYSTEM.md`, `.claude/context/CONVENTIONS.md`

**Updates after completion**: `.claude/memory/DESIGN_DECISIONS.md`, `.claude/memory/PROJECT_STATE.md`

---

## When to Use This Agent

Run this agent ONCE at project start, or when the client provides a new brand guide. It must complete before any screen or widget work.

---

## Input Required from User

Before starting, ask the user for (in one message, grouped):

```
1. PRIMARY COLOR (hex)      — main brand color
2. SECONDARY COLOR (hex)    — accent / secondary brand color
3. ERROR COLOR (hex)        — default #DC2626 if not provided
4. SUCCESS COLOR (hex)      — default #16A34A if not provided
5. WARNING COLOR (hex)      — default #D97706 if not provided

6. PRIMARY FONT FAMILY      — e.g. "Inter", "Poppins", "Roboto"
   - Font file location in assets/fonts/ (or Google Fonts package name)
7. SECONDARY FONT FAMILY    — optional, for display/headings

8. BASE SPACING UNIT        — default 4.0 (all spacing is multiples of this)
9. BORDER RADIUS STYLE      — sharp (4px), rounded (8px), pill (16px)
10. DARK MODE               — yes / no / system-default

11. DESIGN REFERENCE        — Figma link or uploaded screenshot (optional)
```

Do NOT proceed until all required fields (1–10) are provided.

#### A3. `lib/core/design_management_system/tokens/app_spacing.dart`

All spacing is derived from the user's `BASE_SPACING_UNIT` (default 4.0).

```dart
import 'package:flutter/material.dart';
import 'package:flutter_screenutil/flutter_screenutil.dart';

abstract final class AppSpacing {
  static const double _base = 4.0; // USER BASE UNIT

  static double get xs   => (_base * 1).w;   //  4
  static double get sm   => (_base * 2).w;   //  8
  static double get md   => (_base * 4).w;   // 16
  static double get lg   => (_base * 6).w;   // 24
  static double get xl   => (_base * 8).w;   // 32
  static double get xxl  => (_base * 12).w;  // 48
  static double get xxxl => (_base * 16).w;  // 64

  // EdgeInsets helpers
  static EdgeInsets get xsPadding  => EdgeInsets.all(xs);
  static EdgeInsets get smPadding  => EdgeInsets.all(sm);
  static EdgeInsets get mdPadding  => EdgeInsets.all(md);
  static EdgeInsets get lgPadding  => EdgeInsets.all(lg);
  static EdgeInsets get xlPadding  => EdgeInsets.all(xl);

  static EdgeInsets get smHorizontal  => EdgeInsets.symmetric(horizontal: sm);
  static EdgeInsets get mdHorizontal  => EdgeInsets.symmetric(horizontal: md);
  static EdgeInsets get lgHorizontal  => EdgeInsets.symmetric(horizontal: lg);

  static EdgeInsets get smVertical    => EdgeInsets.symmetric(vertical: sm);
  static EdgeInsets get mdVertical    => EdgeInsets.symmetric(vertical: md);
  static EdgeInsets get lgVertical    => EdgeInsets.symmetric(vertical: lg);

  static EdgeInsets get screenPadding => EdgeInsets.symmetric(horizontal: md, vertical: lg);

  // SizedBox helpers
  static SizedBox get xsHeight  => SizedBox(height: xs);
  static SizedBox get smHeight  => SizedBox(height: sm);
  static SizedBox get mdHeight  => SizedBox(height: md);
  static SizedBox get lgHeight  => SizedBox(height: lg);
  static SizedBox get xlHeight  => SizedBox(height: xl);

  static SizedBox get xsWidth   => SizedBox(width: xs);
  static SizedBox get smWidth   => SizedBox(width: sm);
  static SizedBox get mdWidth   => SizedBox(width: md);
  static SizedBox get lgWidth   => SizedBox(width: lg);
  static SizedBox get xlWidth   => SizedBox(width: xl);
}
```

### Phase B — Asset Registration

After tokens are filled, generate the `pubspec.yaml` font block:

```yaml
fonts:
  - family: PrimaryFontName
    fonts:
      - asset: assets/fonts/PrimaryFont-Regular.ttf
        weight: 400
      - asset: assets/fonts/PrimaryFont-Medium.ttf
        weight: 500
      - asset: assets/fonts/PrimaryFont-SemiBold.ttf
        weight: 600
      - asset: assets/fonts/PrimaryFont-Bold.ttf
        weight: 700
```

Also ensure `assets/fonts/` directory contains the actual font files. If using Google Fonts package instead, note it in `DESIGN_DECISIONS.md` and skip asset registration.
